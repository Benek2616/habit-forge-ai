# 🔥 HabitForge AI

Inteligentna aplikacja do budowania nawyków.

## Co potrafi?

- Tworzysz własny nawyk
- Wybierasz częstotliwość i poziom trudności
- Aplikacja generuje spersonalizowany plan na dziś
- Śledzisz postępy (seria dni z rzędu + siatka 7 dni)
- Dostajesz inteligentne wskazówki zależne od Twojego streaka
- Wszystko zapisuje się lokalnie w przeglądarce

## Jak uruchomić?

### Szybki podgląd:
https://htmlpreview.github.io/?https://github.com/Benek2616/habit-forge-ai/blob/main/index.html

### Stały link (GitHub Pages):
1. Wejdź w **Settings → Pages**
2. Source: **Deploy from a branch** → `main` / root
3. Save
4. Po chwili aplikacja będzie pod:  
   `https://benek2616.github.io/habit-forge-ai/`

## Technologie
Czysty HTML + CSS + JavaScript + localStorage  
Zero zależności, działa offline.
